# RAHVENZ AI

A privacy-conscious, Hindi-speaking Android AI assistant. Built with Kotlin + Jetpack Compose, from a phone, via GitHub.

## Status
- Phase 1 (current): app skeleton, English UI, navigation, Hindi TTS replies, local Hindi commands (time/date/greetings/stop). Fully offline. No INTERNET permission.

## Build
Debug APK is built by GitHub Actions. See `.github/workflows/build-debug-apk.yml`.
This is a DEBUG build for personal testing only — not a signed release.

## Security
See SECURITY.md. No hardcoded secrets. No analytics or ads.
